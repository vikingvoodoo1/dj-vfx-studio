🎛️ DJ HARDWARE & SOFTWARE SETUP GUIDE
DJ VFX Studio supports plug-and-play synchronization with every major DJ hardware & software ecosystem:
💿 Pioneer DJ (CDJ / XDJ / Rekordbox)
• Standalone Hardware (CDJ-2000NXS2, CDJ-3000, XDJ-XZ/RX3): Connect your DJ laptop to the Pioneer network switch / Wi-Fi router. The bridge automatically listens on UDP ports 50000 and 50002 for Pro DJ Link beat packets and deck speeds.
• Rekordbox DJ Performance Mode (DDJ/FLX Controllers): Enable Ableton Link in Rekordbox top bar for beat sync, or use the live session file watcher.
🎛️ Native Instruments Traktor Pro 3 & 4
• Live Track Titles: Traktor's internal session history (.nml) in your Documents folder is monitored automatically. New tracks are recognized the instant they are loaded onto Decks A/B/C/D.
• BPM & Beat Sync: Click the LINK button in Traktor's top header to broadcast clock over Ableton Link.
🎧 Denon DJ Engine OS (Prime 4, SC6000, SC Live)
• Plug Ethernet or connect Wi-Fi to your Prime unit. The bridge auto-discovers players over UDP 50010 and streams real-time 4-deck faders, track waveforms, and beat positions.
🌐 Universal REST API, Snip & File Drop
• HTTP REST Push: POST http://localhost:8080/api/nowplaying with body Artist - Title.
• File Drop: Save current track text to nowplaying.txt in the project directory (supported by Snip, Tuna, Serato, VirtualDJ).
